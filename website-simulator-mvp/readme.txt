== Description ==

O **Website Simulator MVP** e um plugin WordPress que permite criar um simulador de criacao de websites para agencias, freelancers e profissionais de marketing digital.

Com este plugin, seus clientes podem:
* Responder a um questionario inteligente sobre o projeto
* Visualizar uma previa responsiva do site em tempo real
* Receber uma estimativa comercial transparente
* Gerar uma proposta comercial em HTML

Para voce (administrador):
* Criar e gerenciar perguntas personalizadas
* Configurar regras de preco flexiveis
* Visualizar todas as simulacoes e leads
* Exportar dados para CSV

== Installation ==

1. Faca upload do diretorio `website-simulator-mvp` para `/wp-content/plugins/`
2. Ative o plugin pelo menu Plugins no WordPress
3. Acesse Website Simulator no menu administrativo

== Shortcodes ==

[website_simulator] - Exibe o simulador completo
